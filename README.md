Welcome to my personal website's repository! This is where I showcase my projects, share my thoughts, and connect with fellow developers. Built with [Zola](https://www.getzola.org/) and deployed on GitHub Pages, it's designed to be fast, beautiful, and developer-friendly.

## 🚀 Develop

1. Install required softwares:

   - [Git](https://git-scm.com/)
   - [Zola](https://www.getzola.org/)

2. Clone the repository:

   ```bash
   git clone git@github.com:lucasguesserts/lucasguesserts.github.io.git website
   cd website
   ```

3. Start the development server:

   ```bash
   zola serve # --port <PORT>
   ```

4. Open `http://127.0.0.1:1111` (or the port Zola is running on) in your browser

5. Build the site for production:

   ```bash
   zola build # --output-dir <OUTPUT_DIR>
   ```

   The built site will be in the `public` directory (or the directory specified with the `--output-dir` flag).

6. Deploy: this site is automatically deployed to GitHub Pages when changes are pushed to the main branch. The deployment is handled by GitHub Actions.
