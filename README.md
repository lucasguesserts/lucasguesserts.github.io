# Lucas Guesser's Personal Website

This serves as my personal website. Currently, I am developing it to contain my portfolio.

## Run locally with [Vite](https://vite.dev/)

```sh
npm install
npx vite docs/
# vite prints the information to open the page
```

Dependencies:

1. `node v22.14.0`;
2. `npm 10.9.2`;
