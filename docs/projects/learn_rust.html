Project: Learn Rust

Motivation

I like very much the memory management of C++ because we can choose how much control we want to have over the memory. For instance, we can control memory layout, allocation and deallocation, we can choose between pass-by-value and pass-by-reference, etc. Moreover, we can specify when to allocate memory (new/delete) but we can also delegate such work to data structures (vector, map).

There is a famous quote of Bjarne Stroustrup:

C makes it easy to shoot yourself in the foot; C++ makes it harder, but when you do it blows your whole leg off.

Ignoring the comparison between C and C++, the relevace for me is how hard it is to find and fix memory problems in C++.
